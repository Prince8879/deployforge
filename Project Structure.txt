1. Har folder ka kaam

app/ — Application code
Flask application, API routes, configuration aur Prometheus metrics expose karne ka code.



tests/ — Automated testing
Health endpoint, application routes aur metrics ke tests. pytest se run honge.



docker/ and deploy/ — Containerization
Docker image build karna, local containers run karna aur production services configure karna.



.github/workflows/ — CI/CD
ci.yml tests run karega, docker-publish.yml image publish karega, aur deploy.yml deployment automate karega. Har workflow apne phase mein enable hoga.



infrastructure/aws/ — Cloud infrastructure
EC2 setup instructions, deployment preparation aur security checklist.



monitoring/ — Observability
Prometheus metrics scraping aur Grafana datasource/dashboard configuration.



docs/ — Documentation
Architecture, installation, deployment, monitoring aur troubleshooting guides.
