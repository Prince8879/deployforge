# DeployForge

A hands-on DevOps project for learning application development, containerization, CI/CD, cloud deployment, and monitoring.

## Project Goals

- Build a lightweight Flask web application.
- Implement health checks and automated tests.
- Containerize the application with Docker.
- Automate testing and image publishing with GitHub Actions.
- Deploy the application to a Linux server and AWS EC2.
- Monitor application health and metrics using Prometheus and Grafana.
- Apply secure configuration and deployment practices.

## Technology Stack

- Python
- Flask
- Pytest
- Git and GitHub
- Docker and Docker Compose
- GitHub Actions
- GitHub Container Registry (GHCR)
- AWS EC2
- Prometheus and Grafana

## Development Roadmap

1. Foundation and Application
2. Containerization
3. Continuous Integration
4. Image Registry and Continuous Deployment
5. AWS Deployment
6. Monitoring and Finalization

## Project Status

Phase 1 - Foundation and Application: In progress.

## Learning Approach

Each phase will include implementation, testing, troubleshooting, documentation, and Git version control.

## Security

- Never commit secrets, credentials, private keys, or real environment files.
- Use least-privilege access for cloud resources.
- Verify changes before committing and deploying.
